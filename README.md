# hello-oss-doc

## Giới thiệu

`hello-oss-doc` là dự án tài liệu mã nguồn mở (open-source documentation), cung cấp hướng dẫn, ví dụ và tài nguyên tham khảo cho cộng đồng lập trình viên. Dự án được xây dựng với mục tiêu minh bạch, dễ đóng góp và dễ sử dụng.

## Mục tiêu

- Cung cấp tài liệu rõ ràng, chính xác và dễ tiếp cận cho người dùng và lập trình viên.
- Khuyến khích sự đóng góp từ cộng đồng để liên tục cải thiện chất lượng nội dung.
- Duy trì một nguồn tài liệu thống nhất, có thể tái sử dụng cho nhiều dự án OSS khác nhau.

## Hướng dẫn build và chạy

### Yêu cầu

- [Node.js](https://nodejs.org/) >= 18 (hoặc công cụ phù hợp với stack của dự án)
- [Git](https://git-scm.com/)

### Cài đặt

```bash
git clone https://github.com/roonau12-creator/-hello-oss-doc.git
cd -hello-oss-doc
npm install
```

### Build

```bash
npm run build
```

### Chạy chương trình

```bash
npm start
```

### Chạy ở chế độ phát triển

```bash
npm run dev
```
